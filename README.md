# NeoTracker Experiment

Eye-tracking experiment for studying Italian neologisms.

## Setup

**Python**: 3.10.11

```bash
pip install -r requirements-neologism_it.txt
```

## Run

```bash
python experiment_implementation/start_multipleye_session.py
```
